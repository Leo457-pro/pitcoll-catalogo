# PITCOLL - Catalogo (URL fija para QR)

Este repositorio alimenta la URL fija que apunta el QR eterno:
https://leo457-pro.github.io/pitcoll-catalogo/

## Como actualizar el catalogo SIN cambiar el QR

1. Entra a esta carpeta del repo en GitHub y usa **Add file > Upload files**.
2. Sube el nuevo PDF con el **mismo nombre**: `catalogo.pdf` (esto reemplaza el anterior).
3. Haz commit. En unos segundos GitHub Pages publica la nueva version.

El QR NO cambia porque siempre apunta a la misma direccion del repo.

Si en algun momento el archivo se llama distinto, edita `index.html` y cambia las dos apariciones de `catalogo.pdf` por el nombre nuevo. No cambies el nombre del repositorio ni la URL de Pages.
